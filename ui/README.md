# COZY 프런트엔드

React와 바닐라 JavaScript로 만든 Vite 기반 프런트엔드입니다.

## 요구 사항

- Node.js 20.19+ 또는 22.12+
- npm

## 시작하기

```bash
npm install
npm run dev
```

개발 서버가 출력하는 로컬 주소를 브라우저에서 엽니다.

## 명령어

```bash
npm run dev      # 개발 서버와 HMR 실행
npm run lint     # Oxlint 검사
npm run build    # 프로덕션 빌드
npm run preview  # 프로덕션 빌드 미리보기
```
